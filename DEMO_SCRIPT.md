**0:00–0:25** — Reload to show the diagnostic boot and its skip option. Point out the original CSS starfield, subtle CRT toggle, and Archive Edition identity.

**0:25–0:55** — Open Inbox, My Computer, and Settings. Drag a title bar, minimize it, restore it from the taskbar, change wallpaper, then show the saved preference.

**0:55–1:45** — Read Mara’s mail. In My Computer open `letters/from-mara.txt`; in Terminal run `ls`, `cat letters/from-mara.txt`, `scan`, and `recover A1`.

**1:45–2:25** — Open BYTE RUNNER, show movement and hazards, explain the level-two fragment and its accessibility fallback. Return to Terminal and run `recover B2`.

**2:25–3:00** — Reopen mail, read the private archive message, `cat /archive/final-journal.txt`, and `recover C3`. Refresh to demonstrate persisted recovery state. Mention all files and commands are simulated locally; no real shell executes.
