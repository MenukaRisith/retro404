# RETRO//404 design system

The app uses the exact palette from the build brief as CSS tokens in `src/styles/tokens.css`: midnight teal is the field, warm gray is tactile window chrome, cyan/green signal interaction, and amber is reserved for recovery discoveries. Pixelify Sans is UI chrome, VT323 is diagnostics, Press Start 2P is display-only, and IBM Plex Mono carries readable copy.

Windows are square, two-pixel beveled panels with 34px navy-to-teal title bars and crisp offset shadows. Icons are original CSS pixel shapes, avoiding copied OS art and emoji. CRT scanlines are subtle, removable, and reduced motion is respected. Focus is deliberately high-visibility for keyboard access.
